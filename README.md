# European Bank Customer Churn Prediction

## Project Overview
This project uses machine learning to predict whether a bank customer is likely to leave the bank. It helps identify customers at risk of churn and supports better customer retention decisions.

## Project Objectives
- Analyze customer data and identify churn patterns.
- Perform customer segmentation and exploratory data analysis.
- Build and compare machine learning models.
- Predict customer churn probability.
- Identify important factors influencing customer churn.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Plotly
- SHAP
- Excel

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## Project Results
- Dataset: 10,000 customer records
- Overall churn rate: 20.37%
- Best model accuracy: 87.1% (Gradient Boosting)
- Random Forest accuracy: 84.6%
